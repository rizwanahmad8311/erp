{% comment %} The filter bar. One component, every report. The fields on it are whatever the report declared (apps/reports/registry.py::Report.filters), rendered in that order by apps/reports/criteria.py::ReportFilterForm — so "As of" is in the same place, spelled the same way, on all eighteen of them. A screen that spelled it differently from the one next to it is a screen people learn twice. It submits by GET, so a filtered report is a URL: bookmarkable, mailable, and one `&format=csv` away from the same figures in a spreadsheet. `.no-print` throughout: this is a control, not a document. When somebody hits Ctrl+P the bar disappears and what is left on the page is the report. {% endcomment %}
